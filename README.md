# Baixador de Vídeo/Áudio com YT-DLP

### O baixador consiste em um script powershell executado por intermédio de um arquivo python.
> Este projeto foi desenvolvido em conjunto com uma inteligência artificial no intuito de deixar o download desses arquivos um pouco mais prático e rápido.


## Requisitos

- Ter o yt-dlp instalado na sua máquina.
- Python, para executar o arquivo .py.

## Modo de usar

Apenas execute o arquivo .py e siga as instruções do terminal.
